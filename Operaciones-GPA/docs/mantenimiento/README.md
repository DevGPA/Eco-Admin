# Módulo de Mantenimiento — documentos de diseño

Copias de los documentos con los que se construye el módulo (rama `mantenimiento`).
La fuente viva sigue en `CLAUDE\mantenimiento-gpa\`; si algo difiere, manda `ESPECIFICACION.md`.

| Archivo | Qué es |
|---|---|
| `INSTRUCCIONES.md` | Traspaso a la sesión que construye: modelo en la tabla única, rutas, permisos, importador, lo que no se toca |
| `ESPECIFICACION.md` | Fuente de verdad del diseño (v1.3): activos, semanas, estatus, asignación, correctivos, motor anual, acta |
| `PROCEDIMIENTOS-PROPUESTOS.md` | Los 13 procedimientos que ningún archivo de GPA describe; son propuestas editables desde la app |
| `LECTOR-DEL-PLAN.md` | Cómo se lee el Excel del plan (colores, filas, trampas) y las cifras que deben salir: 233 / 546 / 3 / 57 |

Los datos (catálogo de códigos, plan 2026, agenda de referencia) no se copian al repo: viven en
`CLAUDE\mantenimiento-gpa\` y en el OneDrive de mantenimiento.
