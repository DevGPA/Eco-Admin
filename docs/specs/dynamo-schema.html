01Single-table designpatrón DynamoDB
◆Una sola tabla, múltiples entidades. El patrón single-table de DynamoDB almacena todos los tipos de entidad (Solicitud, FolioFV, FolioCP, Historial) en la misma tabla usando prefijos en las claves. Esto elimina JOINs, minimiza costos y permite operaciones transaccionales entre entidades relacionadas.

La tabla gpa_fletes almacena 4 tipos de entidad usando prefijos en PK/SK:

Prefijo PKPrefijo SKEntidadPropósito
SOL#<uuid>#METASolicitudRegistro completo de la evaluación — estado, resultado, montos, fletera, destino
FV#<folioFV>SOL#<uuid>Índice FVDetección R-091 — FV usada en solicitud aprobada. Una FV puede aparecer en múltiples solicitudes (rechazadas), pero solo en una aprobada
CP#<folioCP>SOL#<uuid>Índice CPDetección R-092 — CP existe en cualquier solicitud. Una CP nunca puede repetirse independientemente del estado
SOL#<uuid>HIST#<timestamp>HistorialLog de cada acción sobre la solicitud — quién, cuándo, qué cambio de estado
!Ventaja clave para R-091/092: Con este diseño, verificar si un folio ya existe es una operación GetItem directa (O(1)), no un escaneo. La latencia típica es <5ms.

03GSIs — Global Secondary Indexes4 índices
GSIPKSKProyecciónUso principal
estado-fecha-idx estado fechaEmision ALL Monitor kanban por columna · filtro de fechas del dashboard
origen-fecha-idx origenSucursal fechaEmision KEYS_ONLY + folioCP + codigoMotor Ver fletes por sucursal · análisis por origen

→¿Por qué 4 GSIs? Cada GSI tiene un costo de escritura adicional (~4x el costo base). Con 4 GSIs el costo por write sube a ~5 WCUs, pero los patrones de consulta del monitor y auditoría lo justifican. Se puede reducir a 2 GSIs (estado-fecha + origen-fecha) para minimizar costos en el arranque.

05Flujo de evaluación con DynamoDBtransaccional
⚡TransactWrite. La creación de la solicitud y todos sus índices (FV, CP) se hace en una sola operación atómica TransactWriteItems. Si cualquiera falla (ej. condición de unicidad), toda la transacción se revierte. Esto garantiza consistencia sin race conditions.
1. Recibir solicitud (CP + FVs)
API Gateway recibe los folios. Lambda ejecuta el motor v2.4.
2. Pre-validación R-091 / R-092
GetItem(CP#<folioCP>) → si existe → BLOQUEADA R-092.
Query(FV#<folioFV>, filter estado IN APROBADOS) → si hay resultado → BLOQUEADA R-091.
3. Ejecutar capas 1a → C5 del motor
Las capas 1-5 corren en memoria. No requieren DynamoDB. El motor calcula el código R-xxx.
4. TransactWriteItems — escritura atómica
En una sola transacción:
· Put(SOL#uuid · #META) con ConditionExpression: attribute_not_exists(PK)
· Put(CP#folioCP · SOL#uuid) con ConditionExpression: attribute_not_exists(PK) → garantía R-092
· Put(FV#folioFV · SOL#uuid) por cada FV
· Put(SOL#uuid · HIST#timestamp) registro inicial
5. Respuesta al cliente
Retornar id, folioCP, codigoMotor (con concepto), estado, criteriosDetalle[].
06Código — R-091 y R-092Python · boto3
# motor/validaciones.py — Capa 0: Pre-validación documental
import boto3
from botocore.exceptions import ClientError

TABLE = "gpa_fletes"
dynamo = boto3.resource("dynamodb").Table(TABLE)

def verificar_unicidad(folio_cp: str, folios_fv: list[str]) -> dict:
    """
    Capa 0 del motor: verifica R-091 y R-092 antes de evaluar.
    Retorna: {'valido': bool, 'codigo': str, 'detalle': str}
    """
    # ── R-092: CP no debe existir en NINGÚN estado ──────────────
    resp_cp = dynamo.query(
        KeyConditionExpression="PK = :pk",
        ExpressionAttributeValues={":pk": f"CP#{folio_cp}"},
        Limit=1
    )
    if resp_cp["Count"] > 0:
        sol_id = resp_cp["Items"][0]["SK"].replace("SOL#", "")
        return {
            "valido": False,
            "codigo": "R-092",
            "concepto": "CP duplicada",
            "detalle": f"La CP {folio_cp} ya existe en solicitud {sol_id}"
        }

    # ── R-091: FV no debe estar en solicitud APROBADA ───────────
    ESTADOS_APROBADOS = {"AUTO_APROBADA", "APROBADA_MANUAL"}
    for folio_fv in folios_fv:
        resp_fv = dynamo.query(
            KeyConditionExpression="PK = :pk",
            ExpressionAttributeValues={":pk": f"FV#{folio_fv}"}
        )
        for item in resp_fv.get("Items", []):
            if item.get("estado") in ESTADOS_APROBADOS:
                return {
                    "valido": False,
                    "codigo": "R-091",
                    "concepto": "FV duplicada",
                    "detalle": f"FV {folio_fv} ya usada en solicitud aprobada"
                }

    return {"valido": True}
# motor/escritura.py — Escritura transaccional atómica
from datetime import datetime, timezone
import uuid

R_CONCEPTOS = {
    "R-000": "Apoyo completo",   "R-050": "Back Order",
    "R-060": "Cargo envío OK",   "R-101": "Monto insuficiente",
    "R-301": "Destino no cubierto", "R-302": "Ciudad borderline",
    "R-501": "Flete alto > 15%", "R-800": "Dispersión OK",
    # ... todos los 30 códigos
}

def guardar_solicitud(resultado_motor: dict) -> dict:
    sol_id = str(uuid.uuid4())
    ahora  = datetime.now(timezone.utc).isoformat()
    ts     = int(datetime.now(timezone.utc).timestamp())
    ttl    = ts + (7 * 365 * 24 * 3600)  # 7 años

    codigo   = resultado_motor["codigoMotor"]
    concepto = R_CONCEPTOS.get(codigo, codigo)
    folio_cp = resultado_motor["folioCP"]
    folios_fv= resultado_motor["foliosFV"]

    # ── Items de la transacción ──────────────────────────────────
    items = [
        # 1. Solicitud principal
        {"Put": {
            "TableName": TABLE,
            "Item": {
                "PK": f"SOL#{sol_id}",
                "SK": "#META",
                "estado":        resultado_motor["estado"],
                "codigoMotor":   codigo,
                "conceptoMotor": concepto,
                "tipoOperacion": resultado_motor["tipoOperacion"],
                "folioCP":       folio_cp,
                "foliosFV":      folios_fv,
                "origenSucursal":resultado_motor["origenSucursal"],
                "fletaRFC":      resultado_motor["fletaRFC"],
                "destinoEstado": resultado_motor["destinoEstado"],
                "destinoCiudad": resultado_motor.get("destinoCiudad", ""),
                "montoBaseUSD":  resultado_motor["montoBaseUSD"],
                "fleteBaseUSD":  resultado_motor["fleteBaseUSD"],
                "pctFlete":      resultado_motor["pctFlete"],
                "tipoCambioRef": resultado_motor["tipoCambioRef"],
                "incluyeFerry":  resultado_motor.get("incluyeFerry", False),
                "fechaEmision":  resultado_motor["fechaEmision"],
                "fechaEvaluacion": ahora,
                "ttl": ttl
            },
            "ConditionExpression": "attribute_not_exists(PK)"
        }},
        # 2. Índice CP — garantiza unicidad R-092
        {"Put": {
            "TableName": TABLE,
            "Item": {
                "PK": f"CP#{folio_cp}",
                "SK": f"SOL#{sol_id}",
                "estado": resultado_motor["estado"],
                "ttl": ttl
            },
            "ConditionExpression": "attribute_not_exists(PK)"  # ← R-092 a nivel DB
        }},
        # 3. Registro inicial de historial
        {"Put": {
            "TableName": TABLE,
            "Item": {
                "PK": f"SOL#{sol_id}",
                "SK": f"HIST#{ahora}",
                "accion":       "EVALUAR",
                "codigoMotor":  codigo,
                "conceptoMotor":concepto,
                "estadoAntes":  "NUEVA",
                "estadoDespues": resultado_motor["estado"],
                "usuarioId":    "MOTOR_V24"
            }
        }}
    ]
    # 4. Un Put por cada FV
    for fv in folios_fv:
        items.append({"Put": {
            "TableName": TABLE,
            "Item": {
                "PK": f"FV#{fv}",
                "SK": f"SOL#{sol_id}",
                "estado": resultado_motor["estado"],
                "fechaEmision": resultado_motor["fechaEmision"],
                "ttl": ttl
            }
        }})

    boto3.client("dynamodb").transact_write_items(TransactItems=items)
    return {"id": sol_id, "codigoMotor": codigo, "concepto": concepto}
# motor/aprobacion.py — Cambio de estado (aprobador)

def cambiar_estado(sol_id: str, nuevo_estado: str,
                    usuario_id: str, comentario: str = ""):
    ahora = datetime.now(timezone.utc).isoformat()

    # Obtener estado actual primero
    item = dynamo.get_item(
        Key={"PK": f"SOL#{sol_id}", "SK": "#META"}
    ).get("Item", {})

    estado_antes  = item.get("estado", "DESCONOCIDO")
    folio_cp      = item.get("folioCP", "")
    folios_fv     = item.get("foliosFV", [])
    codigo        = item.get("codigoMotor", "")

    items = [
        # Actualizar solicitud
        {"Update": {
            "TableName": TABLE,
            "Key": {"PK": f"SOL#{sol_id}", "SK": "#META"},
            "UpdateExpression": "SET estado=:e, aprobador1Id=:u, comentario=:c",
            "ExpressionAttributeValues": {
                ":e": nuevo_estado, ":u": usuario_id, ":c": comentario
            }
        }},
        # Historial
        {"Put": {
            "TableName": TABLE,
            "Item": {
                "PK": f"SOL#{sol_id}", "SK": f"HIST#{ahora}",
                "accion": nuevo_estado, "estadoAntes": estado_antes,
                "estadoDespues": nuevo_estado, "codigoMotor": codigo,
                "usuarioId": usuario_id, "comentario": comentario
            }
        }},
        # Actualizar índice FV si estado cambió a aprobado
        *[{"Update": {
            "TableName": TABLE,
            "Key": {"PK": f"FV#{fv}", "SK": f"SOL#{sol_id}"},
            "UpdateExpression": "SET estado=:e",
            "ExpressionAttributeValues": {":e": nuevo_estado}
        }} for fv in folios_fv]
    ]

    boto3.client("dynamodb").transact_write_items(TransactItems=items)
    return {"id": sol_id, "estado": nuevo_estado, "aprobador": usuario_id}
# monitor/queries.py — Consultas del dashboard

def get_cola_revision(fecha_desde: str = None) -> list:
    """Columna EN_REVISION del kanban."""
    kwargs = {
        "IndexName": "estado-fecha-idx",
        "KeyConditionExpression": "estado = :s",
        "ExpressionAttributeValues": {":s": "EN_REVISION"},
        "ScanIndexForward": False  # más recientes primero
    }
    if fecha_desde:
        kwargs["KeyConditionExpression"] += " AND fechaEmision >= :f"
        kwargs["ExpressionAttributeValues"][":f"] = fecha_desde
    return dynamo.query(**kwargs)["Items"]


def get_por_rango_fecha(estado: str, desde: str, hasta: str) -> list:
    """Filtro de fechas del selector del dashboard."""
    return dynamo.query(
        IndexName="estado-fecha-idx",
        KeyConditionExpression=
            "estado = :s AND fechaEmision BETWEEN :d AND :h",
        ExpressionAttributeValues={
            ":s": estado, ":d": desde, ":h": hasta
        },
        ScanIndexForward=False
    )["Items"]


def get_kpis_mes(anio: int, mes: int) -> dict:
    """KPIs para el header del monitor."""
    desde = f"{anio}-{mes:02d}-01"
    hasta = f"{anio}-{mes:02d}-31"
    estados = ["AUTO_APROBADA", "EN_REVISION", "AUTO_RECHAZADA",
               "APROBADA_MANUAL", "RECHAZADA_MANUAL"]
    totales = {}
    for e in estados:
        items = get_por_rango_fecha(e, desde, hasta)
        totales[e] = len(items)
    totales["TOTAL"] = sum(totales.values())
    return totales
