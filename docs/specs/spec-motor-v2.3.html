Motor de fletes GPA

Versión 2.3 — validada contra 28 documentos reales (2 batches). Incorpora multi-origen, C4a por FV, ferry en flete, categorías de producto extendidas y excluidos pequeños por presentación.

v2.3Cambios respecto a v2.2
C4a reescrito: fuente de verdad es el campo "Entrega" de la FV, NO el encabezado de la CP. "SERVICIO OCURRE" de la fletera es clasificación interna — no bloquea C4a.
Multi-origen: programa válido desde todas las sucursales GPA (GDL, CDMX, MTY, CUN, PVR, SJD). Dispersiones internas permanecen GDL-only. Nuevo campo origenSucursal en CartaPorte.
Ferry incluido en fleteBaseUSD: todas las líneas del subtotal de la CP (flete, entrega, combustible, ferry, maniobras) forman el monto del flete para C5.
Categorías de producto extendidas: MATERIAL_INSTALACION (adhesivos, pegas pool) y EXCLUIDO_PEQUEÑO (presentaciones ≤25kg / ≤50L) con reglas propias de C1.
Nuevos criterios C1 variantes: R-104 (accesorios sin mínimo $1,000) y R-105 (eligibles <50% del total con accesorios).
4 nuevos códigos R: R-104, R-105, R-401-D, R-401-S.
6 nuevos parámetros: MONTO_MIN_ACCESORIOS, PROP_MIN_ELEGIBLE, PESO_MAX_EXCLUIDO_P, VOLUMEN_MAX_EXCLUIDO_P, SUCURSALES_VALIDAS, SUCURSAL_ORIGEN_DISP.
Catálogo R-xxx ampliado a 30 códigos. Validado: 28 docs reales, 2 batches.
01Flujo de ejecución6 capas · v2.3
Capa 0 — Pre-validación documental
FOR EACH fv: IF DB.exists(folioFV, APROBADOS) → R-091 IF DB.exists(folioCP, TODOS) → R-092
Capa 1a — GS0231 → DISPERSION_INTERNA
IF GS0231 OR destinatarioRFC===GPA_RFC → DISPERSION_INTERNA → Capa 5 // Solo desde GDL. Otros orígenes → R-401-D
Capa 1b — GS0248 → CARGO_POR_ENVIO
IF GS0248 AND sku==='00400000000000' AND desc.includes('CARGO POR ENVIO') delta = |valorFV_MXN - valorCP_MXN| IF delta ≤ valorCP × UMBRAL_CARGO_ENVIO → R-060 ELSE → R-061 · RETURN
Capa 2 — GS0229 / BACK ORDER
IF BACKORDER_EXCEPTION_ENABLED AND (GS0229 OR 'BACK ORDER'): C3 pasa → R-050 · C3 falla → R-301/302 · RETURN
Capa 3 — Motor C1–C5 (fail-fast)
C1 Monto → R-101/102/103/104/105 C2 Producto → R-201/202 C3 Destino → R-301 / R-302 C4a Servicio FV → R-401 // campo Entrega de la FV, NO header CP C4b Sucursal → R-401-S // origen en SUCURSALES_VALIDAS C4c Fletera → R-402 C5 Proporción → R-501/502/601/602 → R-000
Capa 4 — Motor dispersiones (solo GDL→destino)
tarifaRef = TARIFAS_DISPERSIONES[fletera][vehiculo][destino] × pallets IF NOT tarifaRef → R-801 IF flete > tarifaRef×(1+UMBRAL_TARIFA_DISP) → R-802 ELSE → R-800

08Motor C1–C5actualizado v2.3
↑Cambios en C1 y C4 respecto a v2.2. C2 y C3 sin cambios. C5 ahora incluye ferry en fleteBaseUSD.
// ══ C1 MONTO ═══════════════════════════════════════════════════════
montoBaseUSD  = SUM(fv.subtotalSinIVA / tipoCambioRef for each fv)
equipoBaseUSD = SUM(p.importeUSD for partidas EQUIPO + RECUBRIMIENTO)
accsBaseUSD   = SUM(p.importeUSD for partidas MATERIAL_INSTALACION + EXCLUIDO_PEQUENO)
tieneCostal   = ANY(p.categoria === 'EXCLUIDO_GRANDE')
tieneAccs     = ANY(p.categoria === 'MATERIAL_INSTALACION' OR 'EXCLUIDO_PEQUENO')

// Rama 1: hay costal grande (≥25kg / ≥50L)
IF tieneCostal:
  IF montoBaseUSD < MONTO_MIN_COSTAL         → R-103
  IF equipoBaseUSD < MONTO_MIN_EQUIPO_COSTAL → R-102

// Rama 2: hay accesorios o excluidos pequeños (sin costal grande)
ELIF tieneAccs AND NOT tieneCostal:
  IF montoBaseUSD < MONTO_MIN_ACCESORIOS     → R-104  // $1,000 USD
  propElegible = equipoBaseUSD / montoBaseUSD
  IF propElegible < PROP_MIN_ELEGIBLE        → R-105  // 50%

// Rama 3: pedido limpio (solo EQUIPO / RECUBRIMIENTO)
ELSE:
  IF montoBaseUSD < MONTO_MIN_GENERAL        → R-101  // $350 USD

// ══ C2 PRODUCTO ════════════════════════════════════════════════════
// Sin cambios. tieneElegible = EQUIPO || RECUBRIMIENTO únicamente.
// MATERIAL_INSTALACION y EXCLUIDO_PEQUENO NO satisfacen tieneElegible.
IF tieneExcluidoGrande AND NOT tieneElegible → R-201
IF NOT tieneElegible AND NOT tieneAccs       → R-202

// ══ C3 DESTINO ══════════════════════════════════════════════════════
// Sin cambios. Ver spec v2.1 sección 06 C3.

// ══ C4 ENTREGA + SUCURSAL + FLETERA ════════════════════════════════
// C4a: fuente de verdad = campo Entrega de la FV (NO header CP)
IF facturaVenta.campoEntrega !== 'ENTREGA_DOMICILIO' → R-401
// "SERVICIO OCURRE" en CP header es clasificación interna de fletera — IGNORAR

// C4b: sucursal de origen válida  NEW
IF NOT SUCURSALES_VALIDAS.includes(cartaPorte.origenSucursal) → R-401-S

// C4c: fletera autorizada
IF NOT FLETERAS_AUTORIZADAS.includes(transportistaRFC) → R-402

// ══ C5 PROPORCIÓN ══════════════════════════════════════════════════
// fleteBaseUSD = SUM TODAS las líneas de la CP (incluye ferry, maniobras)
fleteBaseUSD = cartaPorte.subtotalSinImpuestos / tipoCambioRef
pct = fleteBaseUSD / montoBaseUSD
IF pct > UMBRAL_FLETE_CRIT → R-502
IF pct > UMBRAL_FLETE_WARN → R-501
→ R-000
09Catálogo de categoríasextendido v2.3
EQUIPO
Equipo de piscina
Motobombas, filtros arena, reflectores, calefactores solares y de calor, cubiertas solar, desnatadores, transformadores, sopladores, paneles, enrolladores.
RECUBRIMIENTO
Revestimiento pool
Vetro Venezia, Cristalo Luxe, azulejo pool (SKU 30131704). Mosaicos y cerámicos para revestimiento de alberca.
MATERIAL_INSTALACION
Accesorios instalación
Pega Veneciana (30111601), mortero vitreo, lechadas, adhesivos para mosaico pool. Condición: pedido ≥$1,000 USD y ≥50% EQUIPO+RECUBRIMIENTO.
EXCLUIDO_PEQUEÑO
Excluido pequeño ≤25kg / ≤50L
Químicos en presentaciones pequeñas: floculante 1L/4L, Alkant 5kg, Zeolita 25kg, cloro granular bolsa pequeña. Condición: igual que MATERIAL_INSTALACION.
EXCLUIDO_GRANDE
Excluido grande >25kg / >50L — activa regla de costal
Tricloro/Dicloro 50kg, costales 20/25/50kg, cuñetes ≥50L de cualquier químico, Diamond Brite, River Rock, material filtrante a granel. Requiere ≥$1,000 total Y ≥$500 en EQUIPO+RECUBRIMIENTO para no ser rechazado.
!Fuente de verdad: catálogo Admin, no el texto de la CP. La descripción de mercancía en la CP puede decir "Químicos para piscinas" aunque la FV contenga Tricloro 50kg. El motor usa el SKU de la FV cruzado con el catálogo.

10Orígenes y sucursalesnuevo v2.3
📍Regla central: VENTA_CLIENTE aplica desde cualquier sucursal GPA. DISPERSION_INTERNA solo desde GDL. Un flete desde SJD→MTY se evalúa con C1–C5 normal, no con tarifas de dispersión.
VENTA_CLIENTE
Todas las sucursales válidas. SUCURSALES_VALIDAS = ['GDL','CDMX','MTY','CUN','PVR','SJD']. Si el origen no está en este catálogo → R-401-S.
DISPERSION_INTERNA
Solo desde GDL (SUCURSAL_ORIGEN_DISP = 'GDL'). Un GS0231 generado desde CDMX u otra sucursal → R-401-D.
C5 multi-origen
El cálculo de C5 usa el mismo tipoCambioRef. Para rutas desde sucursales distintas a GDL, no hay tabla de tarifas de referencia — se aplica únicamente el umbral de % (15%/30%).
origenSucursal
Extraído del campo "Lugar de Expedición" del CFDI o del código de municipio SAP del remitente. Mapeo: 44930/44190→GDL, 09040/09230→CDMX, 64820→MTY, 77510→CUN, 46291→PVR, 23473→SJD.
11Motor dispersionessin cambios · v2.1
