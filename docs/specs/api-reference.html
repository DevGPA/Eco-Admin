◆HTTP API v2 vs REST API. Se eligió HTTP API v2 por ser ~70% más económico ($1.00 vs $3.50 por millón de requests), latencia ~60% menor y configuración más simple. La funcionalidad de proxy Lambda cubre todos los casos de uso del motor.
AuthAutenticación · AWS Cognito JWT
🔐Todas las rutas requieren JWT excepto /health. El token se obtiene autenticándose en Cognito y se pasa en el header Authorization: Bearer {token}.
Obtener token Cognito
# AWS CLI
aws cognito-idp initiate-auth \
  --auth-flow USER_PASSWORD_AUTH \
  --client-id <UserPoolClientId> \
  --auth-parameters USERNAME=oscar@gpa.com.mx,PASSWORD=<pass>

02Evaluación de solicitudes
POST /evaluar Evalúa una solicitud de flete contra el motor v2.4 (6 capas, 30 códigos R-xxx) JWT ▾
folioCP*stringFolio de la carta porte. Verificación R-092: no puede existir previamente.
foliosFV*string[]Lista de folios de factura de venta. Verificación R-091: no puede estar en solicitud aprobada.
origenSucursal*stringGDL · CDMX · MTY · CUN · PVR · SJD
destinoEstado*stringEstado del destinatario. Oaxaca genera R-301. Chiapas requiere destinoCiudad.
destinoCiudadstringRequerido cuando destinoEstado = Chiapas. Autorizadas: Tapachula, Tuxtla Gutiérrez.
fletaRFC*stringRFC de la fletera. C4 verifica contra catálogo de 10 fleteras autorizadas → R-402 si no está.
codigoSAPstringGS0229 Back Order · GS0231 Dispersión · GS0248 Cargo Envío · GS0230 Venta normal
campoEntregaFVstringENTREGA_DOMICILIO (desde FV, no CP). Si es SERVICIO_OCURRE → R-401.
partidas*Partida[]Líneas del pedido. Categorías: EQUIPO · RECUBRIMIENTO · MAT_INSTALACION · EXCLUIDO_P · EXCLUIDO_G
fleteBaseMXN*numberSubtotal del flete s/IVA en MXN. Incluye ferry si aplica.
ferryMXNnumberCargo de ferry en MXN (default 0). Se suma al flete para C5.
tipoCambioRef*numberT/C del día tomado de la FV para convertir a USD.
fechaEmision*stringFecha de emisión YYYY-MM-DD. Clave SK para los GSIs de DynamoDB.
esCFDI4boolTrue si el CP es un CFDI 4.0 con complemento de carta porte v3.1 embebido.
folioPtxGuiastringCódigo de rastreo de la línea GCCR (PTX). Actúa como folioCP para R-092.
costoPtxMXNnumberCosto de la línea GCCR para C5 (PTX).
201AUTO_APROBADA / EN_REVISION / AUTO_RECHAZADA. Solicitud procesada. Retorna id, codigoMotor, concepto, estado, pctFlete, criterios[].
409R-091 / R-092 — Solicitud bloqueada. El folio CP o FV ya existe en la base de datos. Body incluye codigoMotor y concepto.
400Campos requeridos faltantes o destinoCiudad ausente para Chiapas.

07Deploy · AWS SAM
◆Un solo stack. Toda la infraestructura (Lambda, API Gateway HTTP + Cognito JWT, DynamoDB, S3, SQS, SNS, CloudWatch) se define en template.yaml y se despliega con SAM. La configuración por ambiente vive en samconfig.toml.
# 1. Build (SAM empaqueta código + layer)
sam build

# 2. Deploy por ambiente (primera vez: --guided)
sam deploy --guided --config-env prod
sam deploy --config-env prod

# 3. Obtener la URL de la API y demás outputs
aws cloudformation describe-stacks \
  --stack-name gpa-fletes-prod \
  --query 'Stacks[0].Outputs[?OutputKey==`ApiUrl`].OutputValue' \
  --output text
# → https://abc123.execute-api.us-east-1.amazonaws.com/prod
